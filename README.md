# 📊 SuperStore Sales Dashboard

## Project Overview

This project is an interactive Power BI dashboard built using the SuperStore Sales dataset.

The dashboard helps analyze:

- Sales Performance
- Profit Analysis
- Customer Segments
- Regional Sales
- Category-wise Sales
- Monthly Trends

---

## Tools Used

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

---

## Dashboard Features

✔ Sales KPI

✔ Profit KPI

✔ Quantity Sold

✔ Regional Analysis

✔ Category Analysis

✔ Monthly Sales Trend

✔ Interactive Filters
